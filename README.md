A **web-based tool** to generate strong, secure passwords and check their strength in real-time.  
Built with **HTML, CSS, and JavaScript**, this project helps users stay safe by encouraging strong password practices.

---

## 🚀 Features
- ✅ Generate **random secure passwords** instantly.  
- ✅ Customize password length (**6–32 characters**).  
- ✅ Options for including **uppercase, lowercase, numbers, and symbols**.  
- ✅ **Real-time strength meter** to visualize password security.  
- ✅ Copy generated password with a single click.  

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript  
- **Libraries/Tools:** Vanilla JS (no external dependencies)  

---

## 📊 Stats
- 🔢 Supports password lengths up to **32 characters**  
- 🔐 Includes **4 character sets** (upper, lower, digits, symbols)  
- ⚡ Password strength analyzed on **entropy-based scoring system**  
- 🖥️ 100% **responsive design** for desktop and mobile
